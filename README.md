# Paradiso Lounge Bar

Sito statico responsive per il Paradiso Lounge Bar di Nova Milanese.

## Avvio locale

Aprire `index.html` direttamente nel browser oppure avviare un server statico nella cartella del progetto.

La versione attuale include:

- menu Giorno/Notte con cambio automatico in base all'ora e switch manuale;
- listino ricostruito dalle fotografie ricevute;
- carrello, prenotazione e checkout con pagamento in contanti o carta al locale;
- salvataggio locale delle richieste nel browser;
- dashboard `admin.html` con stati ed esportazione CSV;
- mappa e collegamento Instagram.

L'invio automatico di email e SMS, oltre alla condivisione reale dei dati tra dispositivi, richiede un backend e credenziali per un provider di posta e messaggistica.
